## Timing method

Use the same report and the same agreed correctness check for both methods. Record manual conversion time, application import/review/export time, number of corrections, task interruptions and participant experience. Include human review time. Repeat on several reports and report median/range as well as defects. Obtain client agreement on whether the resulting table is acceptable for analysis.

Time reduction = (manual minutes - assisted minutes) / manual minutes × 100%. Estimated monthly hours saved = actual monthly report frequency × observed time saved per report / 60. The client's “about 10 hours/month” is a reported current baseline, not proof that this application saves 10 hours.
